# Захват реальных промптов — по требованию

По умолчанию **не работает и не запускается автоматически**. Включается вручную, когда
нужны настоящие пользовательские запросы для доменного обучения или замера.

## Запуск

```bash
cd ~/PolyStrata
UP_PORT=2524 ~/.gpu-bench/bin/python serve_dialog_logger.py 8090 &
# вывод: dialog logger: listen :8090 -> 127.0.0.1:2524, out ~/eagle_gen/dialogs.jsonl
```

В UI/клиенте адрес меняется на `http://<host>:8090/v1`, API-ключ тот же. Движок при этом
остаётся на своём порту из конфига (`port`, сейчас **2524**) — порт движка ради прокси
не меняем.

Остановить и вернуть клиент на движок:

```bash
pkill -f serve_dialog_logger.py
# в UI: http://<host>:2524/v1
```

## Что пишет

`~/eagle_gen/dialogs.jsonl`, одна запись на завершённый `chat/completions`:

```json
{"ts": 1763..., "messages": [...], "answer": "..."}
```

Стриминг (SSE) проходит насквозь, запись появляется после завершения ответа.
Путь можно переопределить: `OUT_JSONL=/path/file.jsonl`.

## Приватность и уборка

Файл содержит всё, что видел прокси, **включая возможные секреты**. Правила:

1. не коммитить и не копировать в корпус как есть;
2. после использования удалить:
   ```bash
   rm -f ~/eagle_gen/dialogs.jsonl
   ```
3. для обучения — только через конвертер, он маскирует `hf_*`, `sk-*`, `ghp_*`, JWT,
   `bearer`, `api_key=...`:
   ```bash
   python3 dialogs_to_corpus.py ~/eagle_gen/dialogs.jsonl ~/eagle_gen/dialogs_corpus.txt
   ```
4. проверить, что в тексте не осталось ключей:
   ```bash
   grep -c -E "hf_[A-Za-z0-9]{30,}|sk-or-v1-[A-Za-z0-9]{40,}" ~/eagle_gen/dialogs_corpus.txt
   ```
5. после сбора дампов удалить и текст, и производные дампы (`~/eagle_taps_*dlg*`,
   `~/eagle_taps_gen`).

## Кто читает захваченное

- `eagle_collect_decode.sh` — только по явному `DIALOGS_JSONL=<файл>`; автоподстановки
  `~/eagle_gen/dialogs.jsonl` больше нет;
- `ft_dialogs.sh` — только по явному `DIALOGS=<файл>`, иначе скрипт падает с подсказкой;
- `eagle_retrain_night.sh` / `eagle_night10.sh` — берут `DIALOGS_TEXT`, если файл есть;
  если его нет, просто пропускают диалоговую часть.
