# EAGLE-3 отладка: реестр и как убрать

Всё временное помечено в коде маркером **`DBG(eagle3)`** — убрать одним проходом:

```bash
grep -rn "DBG(eagle3)" src/        # что удалять
```

## Ключи окружения (в конфиге `"env"`)

| Ключ | Что делает | Чем заменить после отладки |
|---|---|---|
| `STRATA_EAGLE_STATS` | печатает точность top-1 первого драфта в конце ответа | оставить как диагностику либо удалить |
| `STRATA_EAGLE_ONE_DRAFT` | 1 драфт на раунд без весов политики (измерительный режим) | удалить |
| `STRATA_EAGLE_FORCE_GUESSES` | все драфты в окно, без учёта времени (медленно!) | удалить |
| `STRATA_EAGLE_DUMP` | пишет стадии головы (taps, fc, emb, ln1, hnorm, normed, logits) | удалить |
| `STRATA_EAGLE_DUMP_R` | пишет потоки трёх tap-слоёв | удалить |
| `STRATA_EAGLE_DUMP_ATT` | пишет q/k/v/o внимания первого teacher-шага (`tools/eagle_check_attn.py`); дамп снимается в `midlayer` сразу после `attend_batch` — дальше `o_` перезаписывает down-проекция | удалить |
| `STRATA_EAGLE_TEACH` | голова спрашивается на известных позициях (точность против реального следующего токена) | удалить |
| `STRATA_EAGLE_TEACH_PERM` | TEACH на всех 6 порядках трёх taps | удалить |
| `STRATA_EAGLE_ROPE_PLAIN` | устарел: заменён на `STRATA_EAGLE_ROPE_SCALE` | удалён |
| `STRATA_EAGLE_ROPE_SCALE` | величина cos/sin rope головы (эффективная): по умолчанию 1 — как у transformers 4.57 для `mscale == mscale_all_dim` | оставить 1 |
| `STRATA_EAGLE_ROPE_NEOX` | `0` — строки q/k как в файле (пары-соседи, конвенция форка); по умолчанию 1 — перестановка под split-half (`rotate_half`) | оставить 1 |
| `STRATA_EAGLE_CAT` | порядок полувходов конката: `eh` (по умолчанию) / `he` | удалить |
| `STRATA_EAGLE_TAPS` | выбор свёртки потоков: mean/mix/ffn/attn/s0..s3 | оставить победителя, остальное вырезать |
| `STRATA_EAGLE_TAP_SHIFT` | сдвиг номеров tap-слоёв | удалить (выбран 0) |

## Точки в коде

- `src/poly/eagle3.cu`
  - `dbg_inj_` — печать диапазона taps на первом инжекте
  - `dbg_att_` — печать выхода внимания на первом инжекте
  - `g_att_path` / `g_att_armed` / `g_att_done` — статические ворота дампа внимания (ставит `teacher_step`, снимает `midlayer`)
  - блок `STRATA_EAGLE_DUMP` в `inject()` (7 стадий в файл)
  - блок `STRATA_EAGLE_DUMP` в `draft_logits()` (дописывание logits)
  - `cat_he_` / `STRATA_EAGLE_CAT` — порядок полувходов (если выбран `eh`, удалить)
  - `teacher_step()` целиком (TEACH)
- `src/poly/eagle3.hpp` — поля `dbg_inj_`, `dbg_att_`, `dbg_logits_`, `dumped_`, `dumped_logits_`, `cat_he_`
- `src/poly/engine.cpp`
  - `eagle_dbg_` — печать `draft i/3: p=... draft_id -> target_id`
  - счётчик `probe: the draft equals its own input token`
  - `STRATA_EAGLE_TAP_SHIFT`, `STRATA_EAGLE_TAPS` (оставить только выбранный режим)
  - блок `STRATA_EAGLE_TEACH` в `eval()` (вся TEACH-логика + PERM)
  - синхронизации `draft after embed / draft_logits / likeliest` (их можно свернуть в одну)
- `src/poly/engine.hpp` — `eagle_dbg_`, `eagle_taps_`, `tap_row_`, `tap_row_slot_` (нужны только с отладкой taps)
- `src/poly/deepseek4.cpp` — `tap_state_mix` (оставить рабочий режим), `STRATA_EAGLE_DUMP_R`
- `src/poly/deepseek4.hpp` — `tap_rows_`
- `src/poly/main.cpp` — `eagle_stats`, `eagle_hit`, `eagle_tot`, печать `first guess`
- `src/poly/guesses.hpp` — `force()`, `one_draft()`

## Найденные баги (декод-цепь, 2026-11-17)

- **Ранний путь `read()` пропускал инжект taps** — главный. Блок инжекта жил только на хвосте
  staged-пути; ранний путь (`n_calls == 1`, т.е. любой промпт ≤ `rows_` токенов и последний
  короткий чанк любого длинного промпта) возвращался до него. Черновикный кэш не получал
  ПОСЛЕДНИЕ строки промпта — ближайший к декоду контекст, самый весомый при локальном
  внимании. Симптомы: 0% top-1 при живом TEACH (13/18/4.5%), скачки масштаба логитов
  (9.5→19.4), цикл одних и тех же кандидатов по раундам. Фикс: блок вынесен в
  `Engine::eagle_read_tail()`, зовётся из обоих путей; заодно закрыта утечка `taps_host_`
  на раннем пути и на отменах (`return false`).
- Опечатка в TEACH PERM: `{2,0,2}` вместо `{2,0,1}` — дубль перестановки.
- Оставшийся риск: частичное попадание в KV-кэш при возобновлении разговора — строки кэша
  пропускают слои, taps для них не пишутся, в буфере мусор. Для свежих промптов не проявляется.
- **`keep_state(n)` читал строки, которых никто не писал** — раунды ≥2. Пооковый инжект
  окна (`inject(row, n=1)`) оставляет состояние строки в `hidden_[0]`, каждый следующий
  вызов его перезаписывает; `hidden_[1..]` хранил строки ПОСЛЕДНЕГО read-батча — токены
  промпта за тысячи позиций. `keep_state(n)` копировал `hidden_[n-1]` → любой раунд,
  принявший ≥2 черновика, стартовал следующей рекурсией из середины документа. Фикс
  `00e09afe`: `Eagle3::stage_state(slot)` кладёт состояние строки в `hidden_[slot]` сразу
  после её инжекта; зовётся из window() и eval(). (Путь eval уже инжектировал сам — не
  хватало именно раскладки состояний.)
- **Конвенция taps: `mix` подтверждён по SGLang PR #33344 (EAGLE3 для этой пары моделей).**
  Захват: `eagle3_aux_hidden_states.append(self.hc_head(completed, hc_head_fn, hc_head_scale,
  hc_head_base))`, где `completed = hc_post(выход слоя)`. Это ровно наш mode 5. `h.mean(dim=2)`
  из inference/model.py — путь **DSpark** (другой драфтер; SGLang прямо запрещает одновременный
  захват DSpark и EAGLE3). Эксперимент с mean это подтвердил эмпирически: X упал 13%→6%.
  Слои: PR «capture runs before layer(i), reading the output of layer (i-1)… capture at index
  N+1» → ids [1,20,39] = выходы слоёв 1/20/39 — наш захват верен, сдвиг не нужен.
  `eagle_check_taps.py` конвенцию выбрать не может (circular: fc разных свёрток против fc
  движка на угаданной свёртке).
- **Загадка Q8_0 решена: неверный id типа.** `eagle3.cu` передавал в `native_mmvq` литерал `6`,
  а в нумерации `native_mmvq.hpp` (и ggml) `6` — это **Q5_0** (22-байтовые блоки), Q8_0 — **8**
  (34-байтовые). Ядра читали Q8_0-матрицы головы по чужой сетке: нули на нулях, NaN на реальных
  значениях, дегенеративные логиты lm_head (p=1.0). Все прочие вызовы в движке передают настоящий
  `t.type`. С `kTypeQ8_0 = 8` TEACH X = 40.2/39.1% — бит-в-бит с BF16 (40.2/38.4). **lm_head теперь
  Q8_0 по умолчанию** (417 МБ чтения на шаг вместо 786), `STRATA_EAGLE_LM_Q8=0` возвращает BF16.
- Зонды верхнего уровня (top5 + якорь, 6 раундов на фазу) — за `STRATA_EAGLE_TOP5`; трасса раундов —
  за `STRATA_EAGLE_STATS`.
- **Фаза 2 после wrap-up — не баг цепи**: TEACH стабилен бит-в-бит, а декодная траектория зависит от
  состояния экспертного кэша; приёмка гуляет 0.9–23% на одном промпте. FREEZE_EXPERTS делает замер
  воспроизводимым, но несовместим с ростом KV (shrink_cache при заморозке запрещён → «no VRAM for the
  attention cache»); с Q8_0-lm_head запас VRAM больше — стоит перепроверить.

## Перф-вердикт (2026-11-17, прод-режим без EAGLE_ONE_DRAFT)

- Экономика окна: `t1=68.6ms t2=86.8ms t3=161.7ms ask=3.60ms` — окно из двух = 1.27× токена
  (второй токен 18 ms), окно из трёх = 2.36× (не окупается). Шаг головы после Q8-lm_head — 3.6 ms.
- Гейты (`Guesses`/`Gate`) фильтруют по уверенности головы: приёмка на отобранных раундах
  **66.7%** (14/21), фаза-ответ — гейт не берёт окна (голова не уверена) → чистый eval.
- **Итог: 19.2 tok/s против baseline ~14.5-15.4 = +25-35% на английском/коде.** Русский — гейт
  отступает, скорость остаётся baseline.
- **`EAGLE_ONE_DRAFT=1` — только измерительный флаг**: он принудительно берёт каждый драфт и
  ОТКЛЮЧАЕТ экономику (8-26% приёмки, ноль ускорения). В проде не использовать.
- Порог безубыточности при t2/t1=1.27 и ask=3.6ms — приёмка ≈32%; фильтр гейта даёт 67%.
